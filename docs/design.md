# 全体設計

## 目的・方針
- AtCoder 用。C++ は `g++-15 -std=gnu++23 -O2`。ACL は使わず自作する。（→ 0002）
- 汎用性は高めにする。（→ 0002）
- ライセンスは CC0-1.0（cph fork のみ GPL-3.0-or-later）。（→ 0006）

## ディレクトリ構成・命名
- ライブラリ本体は1つの親フォルダ（名前は未定）にまとめ、その下の階層の深さは固定しない。
- 回答コードからは `include/` の転送用ヘッダを短い名前で include する。`include/` 内は最大3階層。（→ 0004）
- ヘルパー・util の置き場所は自由。
- 1ファイル1機能。依存するものは各ファイルで include する。（→ 0001）

## コーディング規約
- `using namespace std;` を前提にする。自作の名前空間は1つ。（→ 0002）

## cph 展開との約束事
- `#include "..."` はファイル単位で再帰的に展開される。（→ 0001）
- 原則すべてのライブラリで `// @impl` を使い、上に宣言、下に定義を書く。戻り値 `auto` は使わない。（→ 0003）
