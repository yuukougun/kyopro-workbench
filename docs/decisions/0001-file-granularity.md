# 0001 展開はファイル単位、ライブラリは1ファイル1機能

- 日付: 2026-10-25
- 状態: 採用

## 背景
提出時に cph が `#include "..."` を再帰的に展開する。使った関数・クラスだけを展開したい。

## 決定
- シンボル単位（使った関数だけ）の削減はしない。展開はファイル単位で行う。
- ライブラリは1ファイル1機能で細かく分け、依存するものは各ファイルで include する。

## 理由（検討した他の案）
- シンボル単位の削減: C++ の解析（テンプレート、オーバーロード、マクロ等）が必要で、誤るとコンパイルできないコードを提出してしまう。未使用コードが残っても害は小さい（AtCoder のコード長制限は 512KiB）ので見送り。
- ファイルを細かく分ければ、再帰展開によってファイル単位では「使うものだけ」が展開される。
