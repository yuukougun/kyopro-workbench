# 0003 原則すべてのライブラリで `// @impl` を使う

- 日付: 2026-10-25
- 状態: 採用

## 背景
回答コードの main 関数を、展開後もなるべく上に置きたい。

## 決定
- `// @impl` より上には宣言だけを書き、定義は下に書く（下は提出コードの main の後ろに出力される）。
- 上に残すもの: クラスの定義（メンバ変数と関数の宣言）、関数の宣言、型エイリアス、定数。

## 制約（g++-15 で確認済み）
- テンプレートのメンバ関数・関数テンプレートは、定義が main より後にあってもコンパイルできる。
- 戻り値が `auto` の関数は定義より前に使えないので、戻り値の型は明記する。
- コンパイル時に計算に使う `constexpr` 関数は、上に定義を書く必要がある。

## 理由（検討した他の案）
- すべてを include の位置に展開すると、main が提出コードの下の方に埋もれる。
- 定義をクラスの外に書く分だけ記述量は増える。読みやすさの利点のほうが大きいと判断した。
