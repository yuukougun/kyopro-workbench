# 0002 前提と基本方針

- 日付: 2026-10-25
- 状態: 採用

## 決定
- 対象は AtCoder。
- C++ は cph で使っている設定に合わせる（`g++-15 -std=gnu++23 -O2`）。
- ACL は使わず、必要なものは自分好みに改良して実装し直す。
- `using namespace std;` を前提にする。自作の名前空間は1つ（必要になったら増やす）。
- 汎用性は高めにする（テンプレート化して、後から拡張・改善しやすくする）。

## 理由
- 提出先が AtCoder だけなので、そのジャッジの環境に合わせればよい。
- ACL は使い勝手を自分好みに変えられないため。
