# 0006 精進支援ツールも同じリポジトリに入れ、ライセンスは CC0-1.0 にする

- 日付: 2026-11-13
- 状態: 採用

## 決定
- 精進支援ツール（レビュー拡張・Claude 用テンプレート。設計は `docs/dev/review-tool/design.md`）も、このリポジトリに入れる。
- ライセンスは CC0-1.0（ライブラリ・レビュー拡張・テンプレート・docs）。
- cph fork（`_extensions/cph-fork/`）は本家に従い GPL-3.0-or-later とし、本家 https://github.com/agrawal-d/competitive-programming-helper とパッチの元にした版を明示する。

## 理由（検討した他の案）
- 別リポジトリにする案: 目的やライセンスは分けやすいが、cph fork の展開機能とライブラリ・ツールが近くにあり、1か所で管理できる方を選んだ。
- MIT: 使った人に著作権表示を残す義務がある。ライブラリは提出コードに展開して貼るので、厳密には提出のたびに表示が必要になる。CC0 は義務がなく、最も緩い。AtCoder Library も CC0。
- cph fork は GPL の著作物の改変なので、別のライセンスにできない。
